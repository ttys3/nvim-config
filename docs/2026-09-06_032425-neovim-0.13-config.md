# Neovim 0.10–0.13 changelog vs this config

Target runtime: **Nvim 0.12.5** today, **0.13** when it is installable on both **Fedora 44+** and **macOS 26+**. Plugin manager stays **lazy.nvim** (not `vim.pack`). Completion is **builtin** (`vim.lsp.completion` + `'autocomplete'` + `vim.snippet`).

## Same-feature evolution (use the latest stable API)

| Area | 0.10 | 0.11 | 0.12.5 | 0.13 (nightly) |
| --- | --- | --- | --- | --- |
| LSP setup | `lspconfig.setup` | `vim.lsp.config` + `vim.lsp.enable` + `lsp/*.lua` | `:lsp`, `get_configs()` | same + richer completion |
| Default maps | `K`, `[d` `]d` | `grn` `grr` `gra` `CTRL-S` `gri` `gO`; `grt` in 0.11.4 | `grx` (codelens) | `Q` = multicursor (no longer replay register) |
| Comment | `gcc` / `gc` | treesitter `bo.commentstring` | — | — |
| Diagnostics | `enable` new signature; signs via `sign_define` deprecated | `virtual_text` off; `virtual_lines`; `severity_limit` removed | `sign_define` diagnostic signs removed; `disable` / `is_disabled` removed | — |
| Completion | `vim.snippet` | `vim.lsp.completion` | `'autocomplete'`, inlineCompletion | preselect, commitCharacters, nested snippets |
| Highlight yank | `vim.highlight.on_yank` | `vim.hl.on_yank` | same | `vim.hl.hl_op()` (this config falls back on 0.12) |
| Treesitter queries | `iter_matches` `all=false` | `all` default all nodes | `all` removed | perf work |
| uv | `vim.uv` (was `vim.loop`) | — | — | `vim.async` |
| UI | — | — | `_extui` / ui2 opt-in | `vim.ui.img`; cmdwin rewrite |

Do **not** map `gr` to references: it steals the `gr*` prefix (`grn`/`gra`/`grr`/`grt`/`grx`).

### Kept

lazy.nvim, nvim-treesitter (**main** API: `install` + `vim.treesitter.start`), neo-tree, telescope, rustaceanvim, DAP stack, gitsigns / diffview / gitlinker, formatter.nvim (hcl/nomad/proto/stylua), nvim-lint, hop (`phaazon/hop.nvim` v2; archived — consider `smoka7/hop.nvim` later), windline, alpha, ibl, FTerm, surround, repeat, markdown-preview, vim-markdown, nightfox, autopairs (no cmp hook), todo-comments, spectre, easy-align, bqf, colorizer, barbaric (**Linux/fcitx5 only**), crates, local-highlight, gomodifytags / go-impl, miniyank (no yank ring in 0.13).

### Not replaced

- neo-tree: `filetype=directory` is not a file tree
- lazy.nvim: `:packupdate` still has no lazy loading
- hop: builtin `v_an` / `v_in` is not EasyMotion

## Platform (Fedora 44+ and macOS 26+)

- Resolve `python3` and `lua-language-server` via `PATH` (`exepath`). Never hardcode `/usr/bin/python3`, `~/.local/share/lua-language-server`, `/opt/homebrew`, or `/usr/local`.
- Load `vim-barbaric` only when `fcitx5-remote` is executable (Fedora IME). Skip on macOS.
- Clipboard: `unnamedplus` unless inside tmux; let Nvim pick `pbcopy` / `wl-clipboard` / `xclip`.
- Install notes: Fedora `dnf` and macOS `brew`. Apple Silicon vs Intel is PATH-only.
